# POC Scope and Exclusions

## Included

```text
one retailer adapter
one initial product category
manual scrape trigger
raw observation storage
product normalization
matching suggestions
manual match approval
effective price
unit price
search
comparison page
basic settings
test reports
```

## Recommended initial category

Baby diapers are a strong POC category because they include:

```text
brand
size number
package quantity
product form
variant names
promotions
unit comparison
```

## Explicitly excluded

```text
multiple notification channels
automatic schedules
full basket optimization
mobile application
large retailer coverage
all product categories
advanced personalization
multi-provider AI management
complex user and role management
production-scale infrastructure
```

## Scope control

Any new capability discovered during the POC is recorded in the backlog unless it is essential to validate the primary scenario.
