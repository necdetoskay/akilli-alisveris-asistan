# Data Classification and Privacy Controls

## Data classes

### Public

```text
retailer name
public product title
public offer price
public promotion text
```

### Internal

```text
matching rules
operational dashboards
quarantine details
internal identifiers
```

### Confidential

```text
user email
saved baskets
watchlists
notification settings
location preferences
session metadata
```

### Restricted

```text
credentials
tokens
encryption keys
security incident evidence
```

## Privacy principles

```text
collect only necessary data
define retention
support deletion
limit internal access
avoid logging personal data
separate analytics identifiers
document processing purpose
```

## Location data

Location should be stored at the minimum precision required for retailer eligibility and delivery calculations.

## Rule

Do not retain raw user search history indefinitely without a defined product purpose and retention policy.
