# Developer Onboarding and Contribution Workflow

## Onboarding checklist

```text
repository access
runtime installation
pnpm activation
environment setup
local dependencies
database migration
seed data
test execution
first small change
```

## Contribution flow

```text
create branch
 ↓
make focused change
 ↓
run checks
 ↓
update documentation
 ↓
commit
 ↓
push
 ↓
open pull request
 ↓
review and merge
```

## Pull-request requirements

A pull request should describe:

```text
problem
solution
scope
tests
migration impact
operational impact
rollback
screenshots when relevant
```

## Rule

Documentation and tests are part of the implementation, not follow-up work.
