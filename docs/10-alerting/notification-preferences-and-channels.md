# Notification Preferences and Channels

## Supported preference dimensions

```text
enabled channels
quiet hours
maximum alerts per day
preferred retailers
membership availability
promotion inclusion
substitute inclusion
minimum confidence
language and locale
```

## Channels

Potential channels:

```text
in-app
email
push notification
Telegram
```

## Quiet hours

Notifications created during quiet hours may be:

- delayed,
- grouped,
- shown in-app only.

Criticality is low by default because shopping alerts are not emergency notifications.

## Digest mode

Users may choose:

```text
instant
daily digest
weekly digest
```

## Rule

Channel delivery failures must not cause trigger evaluation to run again.
