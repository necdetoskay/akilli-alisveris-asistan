# Explainability and User Choices

## Plan explanation

Each plan should explain:

```text
basket total
item subtotal
delivery and service costs
retailer count
promotion requirements
substitutions
missing items
price freshness
estimated saving
```

## Example

```text
En düşük toplam maliyet: 1.284,70 TL
2 mağazaya bölünüyor.
Ürün toplamı: 1.244,80 TL
Teslimat ücretleri: 39,90 TL
Tek mağazalı seçeneğe göre 76,20 TL daha ucuz.
```

## User controls

Users should be able to select:

```text
Tek mağaza olsun
En fazla iki mağaza
Sadakat kartı fiyatlarını kullan
Alternatif ürün önerme
Yalnızca stokta olanları göster
Teslimat ücretini dahil et
```

## Rule

The recommendation engine should provide choices rather than hide trade-offs.
