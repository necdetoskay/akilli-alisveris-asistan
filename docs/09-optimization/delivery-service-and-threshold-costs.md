# Delivery, Service and Threshold Costs

## Cost types

```text
delivery fee
service fee
small-order fee
minimum basket threshold
membership fee
pickup cost
distance cost
time-window surcharge
```

## Minimum basket

Example:

```text
Retailer A:
items total = 410,00 TL
minimum basket = 500,00 TL
small-order fee = 35,00 TL
```

The effective basket cost becomes:

```text
410,00 TL + 35,00 TL
```

unless the user adds more products.

## Free delivery threshold

Example:

```text
delivery = 29,90 TL
free delivery above 750,00 TL
```

Optimization must evaluate whether shifting products to that retailer reduces total cost.

## Rule

The displayed basket total must identify included and excluded costs.
