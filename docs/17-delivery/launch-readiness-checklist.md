# Launch Readiness Checklist

## Product

```text
critical flows complete
price explanations visible
freshness visible
empty and error states handled
known limitations documented
```

## Data

```text
retailer freshness acceptable
matching precision accepted
unit-price fixtures pass
promotion anomalies reviewed
manual-review backlog manageable
```

## Operations

```text
dashboards available
critical alerts routed
runbooks tested
backup restore verified
on-call owner identified
```

## Security

```text
secrets reviewed
authorization tested
rate limits enabled
audit records verified
dependency scan reviewed
```

## Release

```text
migration rehearsal complete
rollback documented
feature flags configured
pilot users identified
support communication ready
```

## Rule

Launch approval requires product, data, operations, security and release readiness together.
