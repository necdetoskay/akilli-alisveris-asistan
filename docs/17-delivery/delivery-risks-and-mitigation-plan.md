# Delivery Risks and Mitigation Plan

## Major risks

### Retailer instability

Mitigation:

```text
adapter isolation
fixtures
shadow runs
pause controls
fallback behavior
```

### Incorrect matching

Mitigation:

```text
high auto-match threshold
hard conflicts
manual review
golden datasets
audit trail
```

### Scope expansion

Mitigation:

```text
frozen sprint scope
backlog separation
explicit exclusions
vertical slices
```

### Operational overload

Mitigation:

```text
limited pilot
dashboards
runbooks
alert deduplication
retailer-level controls
```

### Migration failure

Mitigation:

```text
expand-contract
staging rehearsal
backup
rollback or forward-fix
```
