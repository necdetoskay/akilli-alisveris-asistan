# POC to Production Transition

## POC purpose

The POC proves:

```text
retailer extraction is feasible
normalization is useful
matching reaches acceptable precision
unit-price comparison provides value
search can retrieve relevant results
```

## POC limitations

The POC may temporarily limit:

```text
retailer count
category count
user count
notification channels
optimization strategies
historical data volume
```

## Production requirements

Before production:

```text
persistent migrations
security controls
observability
backup and restore
rate limits
data retention
incident runbooks
release rollback
support ownership
```

## Rule

POC shortcuts must be documented with an owner and removal milestone.
