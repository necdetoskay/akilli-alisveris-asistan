# Initial Production Scope

## Recommended initial scope

```text
1-2 retailers
1-3 categories
search and comparison
current effective price
unit-price comparison
freshness display
basic administration
manual matching review
operational dashboards
```

## Deferred from initial production

```text
large retailer coverage
all product categories
advanced personalization
multiple notification channels
complex loyalty programs
full basket optimization
mobile application
```

## Success criteria

The initial production release should prove:

- reliable ingestion,
- trustworthy matching,
- correct comparable prices,
- useful search,
- manageable operational workload,
- clear user explanations.

## Rule

Coverage should expand only after quality remains stable.
